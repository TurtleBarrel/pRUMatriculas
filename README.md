# pRUMatriculas

pRUMatriculas is an application for creating college schedules. Features include filtering course sections by desired days/times, automatically marking and optionally hiding conflicting sections, and customizing the graphic schedule's start and end times.

Use of the application requires a file containing the information of all the courses and their sections, which needs to be in a specific format. Files in different formats require changing one script file to allow the application to read them. More information can be found in the wiki.
